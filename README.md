# Supreme — Ficha Técnica One Page

Modelo visual responsivo para fichas técnicas de produtos Supreme Lubrificantes.

## Produto inicial

- Desengraxante Industrial
- Conteúdo integral da ficha técnica original
- Layout adaptado para desktop, tablet, celular e impressão

## Visualização local

Abra `index.html` no navegador ou sirva a pasta com um servidor HTTP estático.
